# 🌸 LunaCare AI

## AI 智能女性健康周期管理系统

LunaCare 是一个基于 Python
的智能健康管理平台，通过数据分析、周期预测和可视化技术，为用户提供温和、科学的数据辅助。

## 核心功能

-   周期记录
-   智能预测
-   趋势分析
-   健康评分
-   个性化建议

## 技术架构

Python + Streamlit + Plotly + SQLite + Machine Learning

## 项目创新

1.  将数据分析应用于女性健康管理场景
2.  结合预测模型提供趋势参考
3.  通过可视化降低用户理解成本

## 启动方式

pip install -r requirements.txt

streamlit run app.py
